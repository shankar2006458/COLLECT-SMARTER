# UPI QR Code Generator

A simple, responsive web application for generating **scan-ready UPI payment QR codes** directly in the browser.

**Collect Smarter** helps you create QR codes for UPI payments, automatically split large amounts, track collection progress, record transaction IDs, and manage previous payment collections from a dedicated Payment History page.

## ✨ Features

### 💳 UPI QR Generation

- Generate scan-ready UPI payment QR codes instantly
- Enter:
  - UPI ID
  - Account Holder Name
  - Total Amount
  - Payment Note
- Works with UPI-compatible payment apps
- No sign-up or account required
- QR codes are generated directly in the browser
- Supports large collection amounts through automatic splitting

### 💰 Automatic Amount Splitting

Each QR code generated by the application can contain a maximum payment amount of **₹1,999**.

If the total amount is higher than ₹1,999, the application automatically divides it into multiple QR codes.

Example:

```text
₹5,000
   ↓
₹1,999 + ₹1,999 + ₹1,002
```

Each amount receives its own QR code, making large collections easier to manage.

### 📊 Payment Summary

After generating the QR codes, the application provides a dedicated **Payment Summary** containing:

- Total amount to collect
- Number of QR codes
- Individual payment amounts
- Collection progress
- Amount collected
- Remaining amount
- Payment completion status
- Transaction ID / UTR information
- Payment checklist

The interface uses a two-step workflow:

```text
STEP 1
Payment Details
      ↓
STEP 2
Payment Summary
```

### 📈 Collection Progress

Track the progress of your collection in real time.

The summary includes:

- Collection progress percentage
- Total amount
- Amount collected
- Remaining amount
- Completed payment count
- Pending payment count
- Visual progress bar

Once all payments are completed, the collection is shown as complete.

### ✅ Payment Tracking

Individual QR payments can be marked as paid.

When confirming a payment, you can enter the corresponding **Transaction ID / UTR** from your UPI app.

The application then stores the transaction ID with that payment and updates the collection progress.

> **Important:** The application does not automatically verify payments. The payment status is based on the information entered by the user.

### 📥 QR Code Download

Individual QR codes can be downloaded as PNG images.

Downloaded QR codes include useful payment information such as:

- Payment amount
- QR code
- Account holder name
- UPI ID
- Payment note
- Collection step

### 🔍 QR Code Viewer

QR codes can be opened in a larger full-screen viewer for easier scanning.

The viewer supports:

- Large QR display
- Payment amount
- Collection step
- Payment information
- Previous / next QR navigation
- Mark as paid
- QR download

### 🖨️ Print All

The **Print All** feature creates a printer-friendly **A4 portrait layout** containing the generated QR codes.

The printable layout includes:

- Collection information
- Account holder name
- UPI ID
- Payment amounts
- QR codes
- Payment notes
- Collection steps

This is useful for physical payment collection sheets.

### 🕘 Payment History

The application includes a dedicated **Payment History** page for managing previous collections.

Each saved collection can display:

- Total collection amount
- Account holder name
- UPI ID
- Payment note
- Number of QR codes
- Amount collected
- Collection progress
- Payment status
- Creation date
- Updated status

Collections can have three statuses:

- **Paid**
- **Partial**
- **Pending**

### 🔎 Search Payment History

Payment History includes a search system that can search collections by:

- Account holder name
- UPI ID
- Payment note
- Amount
- Transaction ID / UTR

### 🏷️ History Filters

Collections can be filtered using:

```text
All
Paid
Partial
Pending
```

This makes it easier to find incomplete or completed collections.

### 🔄 Reuse Previous Collections

A previous collection can be reused directly from Payment History.

The **Reuse** option loads the previous:

- UPI ID
- Account Holder Name
- Amount
- Payment Note

into the generator.

Reusing a collection starts a **new collection** rather than modifying the old one.

### 👁️ View Collection Details

The **View** option opens detailed information about a saved collection.

From the details view, you can:

- View individual QR codes
- See payment status
- View transaction IDs
- Download QR codes
- Copy transaction IDs
- Mark payments as paid
- Reuse the collection details

### 🗑️ Delete & Clear History

Payment History supports:

- Delete an individual collection
- Clear all saved collections
- Confirmation dialogs before destructive actions

Clearing history removes the saved collections from the browser.

## 💾 Data Storage

The application uses the browser's **localStorage** for saving collection data.

Stored information can include:

- Payment details
- Generated payment amounts
- Payment completion status
- Transaction IDs / UTRs
- Payment history
- Unsaved form drafts

The application does not require a custom database or backend.

History is stored locally in the browser, with the application maintaining up to **100 saved collections**.

## 🔒 Privacy

The application is designed to process payment information directly in the browser.

There is:

- No user account
- No sign-up
- No custom backend
- No application database
- No server-side payment processing

Payment and collection information is stored locally using browser storage.

> **Important:** Anyone with access to the same browser profile/device may be able to access locally stored history. Clear your browser data or use the application's **Clear History** option when appropriate.

Always verify the **UPI ID, account holder name, payment amount, and transaction details** before sharing or recording a payment.

## ⚠️ Payment Verification

This application **does not verify UPI payments automatically**.

The **Mark as Paid** feature is a manual collection tracker.

When marking a payment as received:

1. Confirm the payment in your UPI app or bank account.
2. Check the transaction amount.
3. Enter the correct Transaction ID / UTR.
4. Confirm the payment in the application.

The application should not be treated as a payment gateway or banking system.

## 🚀 How to Use

### 1. Enter Payment Details

Open the generator and enter:

```text
UPI ID
Account Holder Name
Total Amount
Payment Note (optional)
```

### 2. Generate QR Codes

Click **Generate QR Codes**.

If the amount is greater than ₹1,999, it will automatically be divided into multiple payments.

### 3. Share the QR Codes

You can:

- Display the QR code on screen
- Open it in the QR viewer
- Download individual QR codes
- Print all QR codes

### 4. Track Payments

When a payment is received:

1. Confirm it through your UPI app or bank.
2. Mark the corresponding payment as paid.
3. Enter the Transaction ID / UTR.
4. Confirm the payment.

The collection progress updates automatically.

### 5. Manage Previous Collections

Open **Payment History** to:

- Search collections
- Filter by status
- View collection details
- Download previous QR codes
- Copy transaction IDs
- Reuse collection details
- Delete collections
- Clear all history

## 🔐 Important Safety Notes

This application generates **UPI payment links and QR codes**.

It does **not**:

- Process payments
- Hold money
- Verify bank transactions automatically
- Access your bank account
- Act as a payment gateway

Always independently verify payments through your official UPI application or bank account.

Never rely only on a screenshot or message claiming that a payment was completed.
